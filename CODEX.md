# Watch Tracker — Codex Guide

`CLAUDE.md` remains the project source of truth.

When updating `data.json`, make the requested data change and verify the diff. Commit and push only when Karl explicitly asks to publish/push the change, or names the commit-and-push workflow in the request. Do not treat a routine progress update as authority for an external push.

For new shows, verify episode counts from the documented source before editing. On an explicit session end, use the capture workflow before a factual checkpoint.
