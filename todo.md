## IMDb import

- **Built 2026-09-12**: `scripts/import-imdb.mjs <path-to-watchlist.csv> --scope=karl|liisa|together`. Scoped down from the original idea per Karl: ratings are NOT imported (the site's own ratings are correct, IMDb's might not be) — only the watchlist export. Unlike Letterboxd, IMDb watchlists mix movies and TV shows in one CSV (`Title Type` column) and carry no episode/season totals for TV, so TV rows import with `total_episodes: null`, default to `category: 'western'`, and get printed in a review list at the end for Karl to flip any anime ones via `supabase-write.mjs`. Both `runtime_minutes` and `genres` come straight from IMDb's own CSV columns (`Runtime (mins)`, `Genres`), so those don't need a separate lookup. Same collision/dedup safeguards as the Letterboxd importer (scoped title match, cross-scope id-collision pre-flight). One real bug caught during testing before it shipped: IMDb's CSV routinely has blank interior fields (e.g. `Description`) that Letterboxd's naive "split on commas outside quotes" regex parser silently drops instead of emitting `''`, shifting every later column left — replaced with a proper char-by-char CSV line parser for this script. (The Letterboxd importer has the same latent parsing approach; it just hasn't hit a blank interior column yet since Letterboxd's own export columns are almost always populated.)

## New-season checker: architecture note (2026-09-11)

- Reworked after Karl flagged two real problems: (1) inserting a new show row per anime sequel was wrong — AniList treats each season as a separate entry, but Karl wants ONE row per show with cumulative episodes/seasons, matching how western shows already work here. Anime new-season detection now bumps the SAME row's `total_episodes`/`total_seasons` instead of inserting, same as western. This also answers "how many seasons have I seen" for free: `current_episode`/`total_episodes` is one cumulative pair, so "finished" always means "caught up to what was out at the time," and a later season bump naturally drops the show back into In Progress. (2) The banner's Dismiss button didn't persist anything — now both Dismiss and Add New Season write a key to a `dismissedSeasonNotices` localStorage list, so a specific detected season won't re-nag once handled either way, while a genuinely later new season (different key) still surfaces normally. (3) Visual redesign shipped same day: collapsed "N new seasons available ▸" bar, expands to a quiet single-line-per-notice list — replaced the original boxed-card stack Karl wasn't sold on.
